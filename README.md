# Практическая работа 2 (ООАиП)

Пакет `pr2.part11` – практическая работа № 11 (работа с датой и временем), задания 1–5.
Пакет `pr2.extra` – дополнительные задания 3–5 (Date, Random, GregorianCalendar).

Запуск: открыть папку в IntelliJ IDEA, у нужного класса с методом `main` нажать зелёную стрелку.
Задания 2 и 4 запрашивают ввод с клавиатуры.
